# 校招 / 实习面试准备

供 `/interview` 在中文校招、应届、在读或实习档案时使用。职业阶段采用档案的 `Career stage: campus` / `intern`；学生身份和毕业年份分开记录。应届毕业生可以已经离校，不推断其仍在读。不要求现职雇主，不生成离职理由或当前工资。

只用 `01-candidate-profile.md`、`CLAUDE.md`、主 CV 和已提交申请中可核对的事实。没有实习可以用课程、项目、社团、竞赛的真实个人贡献；团队成绩要说明分工。缺失的指标、奖项、排名、GPA、毕业时间先标「待确认」，不补写。JD 手工粘贴，不抓取招聘网站，不自动打招呼或投递，不写密钥。

## 自我介绍与申请动机

准备 45 秒和 90 秒两个长度。依次说明专业/学位与在读或毕业状态、一个相关项目或实习中的个人贡献、为何申请这个岗位及可到岗安排。公司事实必须已核实。没有企业实习就直接谈项目，不把在校经历说成任职。

下表是**填写提纲，不是朗读台词**。方括号是待填字段，不能原样放入最终准备稿；未确认项单列为待确认问题，不生成完整答案。

| 信息槽 | 需从档案核对的内容 |
| --- | --- |
| 学业与届别 | [专业]、[在读/已毕业]、[预计毕业年月/届别] |
| 个人贡献 | [项目/实习背景]、[本人负责部分]、[验证结果与局限] |
| 申请动机 | [JD要求]与[已有证据]的对应关系 |
| 可到岗安排 | [起始日期]、[每周天数]、[持续月数]、[课程/论文约束] |

## 群面 / 无领导小组讨论

按现场题目读题、短陈述、自由讨论、总结。先明确目标、评价标准和时间，再比较方案。可以承担计时、记录、澄清和总结；不抢角色，不靠打断别人争表现。反对观点时复述对方依据，再给出自己的理由。总结只覆盖讨论中出现的共识、分歧和风险，不编题目数据。

练习后复盘一次有效推进、一次倾听和一次可改进的表达。群面后的 HR 面常追问自己贡献、分歧处理及为何没有采纳某方案；用现场事实回答，不把全组成果独占。

## 技术面

从 JD 选基础知识与项目深挖：数据结构、语言、数据库、网络或对应岗位基础。按「问题 → 方案选择 → 个人实现 → 验证 → 局限」准备一个真实项目。区分课内演示、本机测试与生产部署，不把合成数据的指标说成线上成果。

手写题先澄清输入、边界和复杂度，再实现、举例验证、解释取舍。不懂就说明已知部分与验证思路；不虚构系统规模、用户量或任职经验。STAR 也可取自课程协作、竞赛与志愿活动。

## HR 面

核对专业、学业时间线、毕业届别、投递方向、城市、到岗安排和学习计划。准备一次合作冲突、一次失败与改进的真实案例。没有工作经历无需解释离职。对照提交版 CV 核对实习起止、奖项级别和自己分工；不得虚构现职雇主、当前工资或其他 offer。

## 笔试 / 测评

按邀请说明确认截止时间、时区、设备、允许资料和监考规则，预留网络与设备检查时间。按岗位练习基础题、编码题、案例或行测；记录错因和复盘。性格测评如实回答。不代考，不在正式测评中提供违反规则的协助。准备包只安排练习与时间，不保存证件或账号凭证。

## 三方协议 / offer 比较

以下是待核对清单，**不是合同结论或法律意见**。以书面 offer、学校就业指导部门和当地主管部门解释为准；不依据口头承诺直接签约。

| 维度 | 向招聘方或学校核对 |
| --- | --- |
| 主体与岗位 | 招聘单位、签约单位、实际用工单位是否一致；岗位、城市、报到时间 |
| 三方协议 | 学校签约流程、签订期限、解约流程、违约金条款、毕业或学位条件；不要把三方协议当成劳动合同 |
| 薪资结构 | 税前月薪与薪数、保证部分与浮动部分、补贴、试用安排、社保公积金基数 |
| 日薪实习 | 元/天金额、计薪出勤日、发放周期、税费/补贴、加班安排；不拿日薪直接比较全职月薪 |
| 户口与编制 | 落户资格、名额、办理条件和失败后的安排；是否有编制、谁书面确认，不能把承诺当保证 |
| 决策与退出 | 回复期限、延期可能、违约金与服务期、未毕业/未获学位的处理方式 |

按用户自己的优先级比较确定收入、岗位成长、导师、城市成本、稳定性和约束。未知项写未知，不编市场价或默认某家公司一定转正。具体薪资只保存在 gitignored 的 `interview_prep_<stage>.md`。

## 实习转正

在校生实习先核对学校要求、实习协议主体、工作内容、时长、保险与安全、保密/IP、退出流程。协议名称本身不能判定实际用工性质。学生使用实习协议不自动视为劳动合同风险；毕业后的用工与签约安排另行核对。

向导师/HR询问转正考核标准、名额是否确定、评审时间、反馈节奏、历史转正数据是否可提供、毕业与正式入职衔接。把「有机会转正」记为待确认，不记为已有 offer。准备一次成果复盘，保留可公开的个人贡献证据，不携带单位保密材料。
