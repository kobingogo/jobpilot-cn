# 模型配置（Claude Code 可选适配：DeepSeek / Kimi / GLM）

通用 Skill 使用宿主 Agent 自己的模型，不读取此文件或 `.claude/settings`。
Codex CLI、Trae、Cursor、Grok Build、Gemini CLI/agy 的入口与限制见
[安装与使用（各平台）](安装与使用（各平台）.md)。下文仅适用于选择 Claude Code 的用户，
保留已有配置示例，不代表已验证其他宿主可以使用 Anthropic 端点。

Claude Code 读的是项目里的 `.claude/settings.local.json` 的 `env`，不是 `.env`，也不是 OpenAI 风格的 `base_url`。仓库只提交占位示例 `.claude/settings.local.example.json`（默认 DeepSeek，token 是 `YOUR_DEEPSEEK_API_KEY`）。在仓库根目录执行：

```bash
cp .claude/settings.local.example.json .claude/settings.local.json
```

然后只改复制出来的那份：把 `ANTHROPIC_AUTH_TOKEN` 换成你自己的 key。`.claude/settings.local.json` 已在 `.gitignore` 里。助手不应创建这个文件，也不应写入 token。

改完后重启 `claude`，在会话里输入 `/status`，确认 Base URL 和 Model。切回 Anthropic：删除 `.claude/settings.local.json` 后再重启。若 `~/.claude/settings.json` 或 shell 里还留着 `ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_API_KEY`，删项目文件不够，那些也会生效。

这里没有爬虫，不自动打招呼，不自动投递。职位描述由人粘贴。选了哪个模型都不改变这一点。

模型名以服务商当前文档为准。下面三块是 2026-10-20 打开官方文档后写的；服务商改名后以他们的页面为准，不要沿用本页的旧名字。

## 隐私

调用其中任何一个时，请求离开你的电脑，发到该服务商的服务器。随请求走的可以包括简历正文、求职信、候选人档案、手贴的职位描述，以及面试准备里的经历和数字。

DeepSeek、月之暗面、智谱都是第三方。本仓库不托管这些模型，也没有把推理锁在本机的配置。发出去之后保存多久、是否用于训练或改进模型，以该服务商当时的隐私政策和 API 条款为准，不由本仓库决定。提交前自己打开服务商的说明看一遍。

不要把身份证号、银行卡号、密码，或档案里未打算公开的薪资数字放进提示词。

`.claude/settings.local.json` 里的 key 是明文。不要提交，不要贴进聊天、文档或追踪表。示例里的 `YOUR_DEEPSEEK_API_KEY`、`YOUR_MOONSHOT_API_KEY`、`YOUR_ZHIPU_API_KEY` 不是钥匙。

不要同时设置 `ANTHROPIC_API_KEY`。Claude Code 这里只用 `ANTHROPIC_AUTH_TOKEN`。两个一起设会抢鉴权，请求会失败或发到错误的凭据。环境变量和 `~/.claude/settings.json` 里如果已经有 `ANTHROPIC_API_KEY`，先删掉再启动。

## DeepSeek（默认）

出处（访问日期 2026-10-20）：[Integrate with Claude Code](https://api-docs.deepseek.com/quick_start/agent_integrations/claude_code/)、[Using the Anthropic API](https://api-docs.deepseek.com/guides/anthropic_api/)。模型名同时对照了当天的 [Models & Pricing](https://api-docs.deepseek.com/quick_start/pricing)：`deepseek-v4-pro` 仍是在售模型；flash 的名字是 `deepseek-flash`。旧名 `deepseek-v4-flash` 仍被接受，但对应模型已退役，请求由现用的 Flash 承接，不要再写进配置。

主对话、opus、sonnet 用 `deepseek-v4-pro`。haiku 和子代理用 `deepseek-flash`。接入页的示例把前三档写成 `deepseek-flash[1m]`、后两档写成 `deepseek-flash`；要跟那一页完全一致就改模型名，不必改 Base URL。

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_DEEPSEEK_API_KEY",
    "ANTHROPIC_MODEL": "deepseek-v4-pro",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "deepseek-v4-pro",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "deepseek-v4-pro",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "deepseek-flash",
    "CLAUDE_CODE_SUBAGENT_MODEL": "deepseek-flash"
  }
}
```

`/status` 里 Base URL 应为 `https://api.deepseek.com/anthropic`，Model 应为 `deepseek-v4-pro`。

## Kimi（月之暗面 Moonshot）

出处（访问日期 2026-10-20）：[在 Claude Code 中使用 Kimi](https://platform.kimi.com/docs/guide/claude-code-kimi)。

主对话、opus、sonnet、子代理用 `kimi-k3`。haiku 用 `kimi-k2.6`（思考可选，适合更短的任务）。`kimi-k2.7-code` 强制开启思考，必须在 Claude Code 里打开 Thinking（macOS `Option+T`，Windows/Linux `Alt+T`），否则返回 `400 invalid thinking`。官方示例把 haiku 设成 `kimi-k2.7-code`，并把主模型写成 `kimi-k3[1m]`（百万上下文）。要 1M 窗口时再改成带 `[1m]` 的名字，并按该页补 `CLAUDE_CODE_AUTO_COMPACT_WINDOW`。

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.moonshot.cn/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_MOONSHOT_API_KEY",
    "ANTHROPIC_MODEL": "kimi-k3",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "kimi-k3",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "kimi-k3",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "kimi-k2.6",
    "CLAUDE_CODE_SUBAGENT_MODEL": "kimi-k3"
  }
}
```

`/status` 里 Base URL 应为 `https://api.moonshot.cn/anthropic`，Model 应为 `kimi-k3`。

## GLM（智谱）

出处（访问日期 2026-10-20）：[Claude Code](https://docs.bigmodel.cn/cn/guide/develop/claude)、[Claude API 兼容](https://docs.bigmodel.cn/cn/guide/develop/claude/introduction)。模型编码对照当天的 [GLM-5.3](https://docs.bigmodel.cn/cn/guide/models/text/glm-5.3) 与 [GLM-5.3-Flash](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)。Coding Plan 的切换说明见 [如何切换模型](https://docs.bigmodel.cn/cn/coding-plan/latest-model)。

主对话、opus、sonnet、子代理用 `glm-5.3`。haiku 用 `glm-5.3-flash`。同一天的 Claude Code 接入页仍写着 `glm-4.7` / `glm-5.2[1m]`，模型页和切换页已经是 `glm-5.3` 与 `glm-5.3-flash`。要 1M 上下文时在模型名后加 `[1m]`（例如 `glm-5.3-flash[1m]`），并按切换页设置 `CLAUDE_CODE_AUTO_COMPACT_WINDOW`。

Coding Plan 的 key 和标准 API 的 key 不通用。个人套餐、团队套餐、模型标准 API 分开管理，不能拿一把 key 去打另一边。模型页还写明：订阅过 Coding Plan（含已过期）时，标准模型 API 暂时只能走 OpenAI Chat Completion。Claude Code 走上面的 Anthropic 端点，用与这个端点匹配的那把 key。

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://open.bigmodel.cn/api/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_ZHIPU_API_KEY",
    "ANTHROPIC_MODEL": "glm-5.3",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-5.3",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-5.3",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-5.3-flash",
    "CLAUDE_CODE_SUBAGENT_MODEL": "glm-5.3"
  }
}
```

`/status` 里 Base URL 应为 `https://open.bigmodel.cn/api/anthropic`，Model 应为 `glm-5.3`。
