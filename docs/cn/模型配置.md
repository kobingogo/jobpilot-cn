# 模型配置（DeepSeek / Kimi / GLM）

可选的第三方模型是 DeepSeek、Kimi（月之暗面 Moonshot）、GLM（智谱）。本页只说明占位配置，以及简历离开本机这件事。

这里没有爬虫，不自动打招呼，不自动投递。职位描述由人粘贴。不要新建 `.env`，不要写入 token。不要把真实简历、身份证号或密钥写进会被提交的文件。

## 隐私

调用其中任何一个时，请求离开你的电脑，发到该服务商的服务器。随请求走的可以包括简历正文、求职信、候选人档案、手贴的职位描述，以及面试准备里的经历和数字。

DeepSeek、月之暗面、智谱都是第三方。本仓库不托管这些模型，也没有把推理锁在本机的配置。发出去之后保存多久、是否用于训练或改进模型，以该服务商当时的隐私政策和 API 条款为准，不由本仓库决定。提交前自己打开服务商的说明看一遍。

不要把身份证号、银行卡号、密码，或档案里未打算公开的薪资数字放进提示词。

`config/models.example.json` 和 `.env.example` 里只有占位符，例如 `DEEPSEEK_API_KEY=your-key-here`。`your-key-here` 不是钥匙。真实密钥只放在你本机、已被 git 忽略的 `.env` 里。助手不应创建那个文件，也不应写入 token。

## 占位文件

`.env.example`：

- `MODEL_PROVIDER`：`deepseek`、`kimi` 或 `glm`
- `DEEPSEEK_API_KEY`
- `MOONSHOT_API_KEY`（Kimi）
- `ZHIPU_API_KEY`（GLM）

`config/models.example.json` 把这三个名字对应到上面的环境变量，并写了公开接口地址示例。地址以服务商当前文档为准。不要把真实 key 写进这个 JSON。

`.env` 已被 `.gitignore` 忽略。不要提交它，不要把 key 贴进聊天、文档或追踪表。

## 不做的事

不抓取 Boss直聘、智联、拉勾、猎聘或任何招聘站。不自动打招呼，不自动投递。职位描述由人粘贴后再评估。选了哪个模型都不改变这一点。
